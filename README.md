# 🩺 Projet de Prédiction du Diabète

## 📌 Description

Ce projet consiste à développer et évaluer des modèles de Machine Learning capables de prédire la présence du diabète à partir de données médicales.

L'objectif est d'explorer différentes techniques de classification, de comparer leurs performances et d'analyser les résultats obtenus.

## 🎯 Objectifs

* Explorer et analyser les données médicales.
* Préparer les données pour l'apprentissage automatique.
* Entraîner différents modèles de classification.
* Comparer leurs performances.
* Évaluer les prédictions obtenues.
* Analyser les résultats.

## 🛠️ Technologies utilisées

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Machine Learning

## 🤖 Modèles utilisés

* Logistic Regression
* Random Forest

## 📊 Résultats

Les performances obtenues lors des expérimentations sont :

| Modèle              | Accuracy |
| ------------------- | -------: |
| Logistic Regression |  75,32 % |
| Random Forest       |  74,03 % |

## 🚀 Installation

Cloner le dépôt :

```bash
git clone https://github.com/Aicharassoul01/Projet_Diabete.git
```

Installer les principales dépendances :

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

Lancer Jupyter Notebook :

```bash
jupyter notebook
```

Puis ouvrir `Projet_Diabete.ipynb`.

## ⚠️ Limites

Ce projet a été réalisé dans un cadre académique. Il ne constitue pas un outil médical destiné au diagnostic réel.

Les performances dépendent notamment du jeu de données et des méthodes de préparation et d'entraînement utilisées.
